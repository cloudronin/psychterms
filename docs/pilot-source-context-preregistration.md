# Source-context qualification of the development pilot

Vishnu authorized API-based retuning on the pilot. A sample audit of the 128 provisional two-reader/copy passes found that source-record labels had not been included in requests. For example, the NCI record **Gene Therapy Agents**, with aliases **Gene Therapy Products**, was used to define **gene therapy** itself. The packet described an agent/product, not the procedure. This is a source-sense error, not a reason to accept a higher count.

Before further paid calls, `data/pilot-source-context-registration.json` froze the 128 proposals, source labels, publisher aliases, prompt, schema, code hash and shared $200 redraft ledger. Neither the definitions nor their original results were overwritten.

Both non-drafter models, `gpt-5.4-mini-2026-03-17` and `gpt-5.2-2025-12-11`, independently rechecked every proposal with its full source-record context. No prior verdict or feedback was shown. The questions were separate: is the definition supported, is the exact sense right, and is this source-grounded meaning within the dictionary’s psychology/neuroscience/methods scope? All three must pass for both readers. Taxonomy flags remain separate publication holds.

The audit used the existing permitted source corpus for labels and aliases. It added no headwords or source permissions, did not expose legacy definitions, did not redraft against a failed packet and did not perform a wider wave. Every actual call and usage record is retained; uncertain attempts stay reserved against the original cap.

## Result

**70/500 (14%)** qualified, compared with the original **16/500 (3.2%)**. The earlier 128 count is retained as a provisional pre-context result. Of the 70, **49** used the original packets, **20** came from unused original retrieval packets and **one** came from the added government sources. **13** have taxonomy flags; **57** have no such flag.

The sample corpus and its failures informed development. These numbers are development yields, not an independent accuracy estimate. The remaining waves did not start, and no definitions were published. The original 2,600 failed entries remain unchanged.

See [the final context-qualified report](../reports/pilot-source-context.md) for all 128 decisions, including reasons for removing 58 provisional proposals. Total receipted redraft-line usage cost, including the original run and all development, is **$10.242282**; **$0.389117** remains reserved for uncertain attempts under the same **$200** cap.

After this executed audit, the code was generalized to accept an explicit parent/destination and integrated as a required completion stage for future pilot runs. Full source-record labels and publisher aliases also reach fit and drafting requests, and taxonomy hints are kept out of definition boilerplate. The reported 70/500 comes from the completed, retained audit; the later generation-path changes were not represented as another measured whole-pilot run.
