# PsychTerms: implementation reference, v0.2

The approved v0.2 spec and Vishnu's recorded decisions govern this project. There is no target count or deadline. Work is evaluated against source permissions, supported definitions, reproducibility and useful delivery.

The legacy derivative corpus is kept outside this repository. Only the parser-audit command may read it, and that command reports aggregate counts, not terms or definitions. It is not a source or vocabulary seed and must never enter a model prompt.

The public export uses an explicit allowlist. Paid API keys, reference corpora, downloaded policy snapshots and prompt caches are not public files. Exact overlapping windows are not duplicate-entry counts. Five-word matches are editorial triage, never blanket rewrite instructions.

Source inventory findings are provisional admission decisions for the stated scope, not blanket permission for whole websites. Each actual packet must be pinned and checked separately. Related-topic links never satisfy the supporting-source requirement. Every release definition needs BOTH independent judges passing the same entry and packet hashes. One editorial redraft is allowed, followed by both judges again; unresolved failures are recorded as drops.
